# 우리 교실

여러 사람이 같은 3D 초등학교 교실에 들어와 함께 머무는 웹 서비스입니다.

## 실행

```
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 포트는 `PORT` 환경변수로 바꿀 수 있습니다.

## 조작

- 바닥 클릭 또는 WASD/방향키: 걷기
- 드래그: 둘러보기, 휠이나 두 손가락: 확대/축소
- 점프 버튼 또는 스페이스 키: 점프
- 책상이나 의자 클릭: 앉기, 아래 메뉴의 앉기 버튼: 가장 가까운 빈자리에 앉기 / 일어서기

- 공부하기 버튼: 빈자리에 앉아 구구단이나 나머지 없는 나눗셈 10문제 풀기 (점수는 내 화면에만 보입니다)

## 구조

- `server.js`: 정적 파일과 WebSocket 서버. 접속 상태는 메모리에만 둡니다.
- `public/js/main.js`: 입력, 카메라, 네트워크, NPC, 화면 UI
- `public/js/world.js`: 교실과 창밖 풍경
- `public/js/avatar.js`: 아바타와 동작
- `public/js/data.js`: 반 정원, 닉네임 단어, 말풍선 문장
- 반 운영: 자습 1반과 추억 1반은 늘 있고, 25명이 차면 서버가 다음 반을 엽니다. 나중에 연 반은 1분 넘게 비면 닫힙니다.
- 글꼴: Pretendard (SIL Open Font License). 전송량을 줄이려고 화면에 쓰는 글자만 남긴 `public/fonts/PretendardSubset.woff2`를 씁니다. 원본은 `tools/`에 있고, 코드에 새 한글 문구를 넣으면 `npm run fonts`로 다시 만듭니다.
- 전송량: 서버가 파일을 압축해 보내고, 브라우저가 이미 가진 파일은 다시 보내지 않습니다. 첫 접속 약 300KB.
- 이용자 수: GoatCounter(`minfp-online-classroom`)로 세고 왼쪽 위에 오늘/전체를 표시합니다. 숫자는 최대 4시간 늦을 수 있습니다.
- `public/js/schedule.js`: 모두 같은 시계로 도는 40분 수업 + 10분 쉬는 시간 (주소에 `?demo=1`을 붙이면 40초 + 10초)

서버 없이 정적 호스팅에 올리면 혼자 모드(NPC만 있는 교실)로 동작합니다.

## 안전 기본값

닉네임, 말풍선, 지역은 정해진 목록의 번호만 주고받습니다. 로그인은 없고 학교 이름이나 실명을 묻지 않습니다. 칠판은 소품이라 어느 교실에서도 글이나 그림을 쓸 수 없고, 서버에도 그 기능이 없습니다. 그래서 다른 사람이 자유롭게 쓴 글이나 그림이 화면에 나올 길이 없습니다.
